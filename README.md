# DYRKA-SERVER

Готовая клиентская сборка Minecraft на базе **Fabric** для версии **1.26.3**. Она создана для комфортной игры с высокой производительностью, красивыми шейдерами и полезными дополнениями (карта, динамический свет).

---

## 🚀 Состав сборки (Что за что отвечает?)

В папке `mods/` находятся следующие модификации:

1. **Fabric API** (`fabric-api-...`) — обязательная базовая библиотека, без которой не работает большинство модов на Fabric.
2. **Sodium** (`sodium-...`) — мощный мод для оптимизации графики. Значительно повышает FPS и убирает лаги.
3. **Iris Shaders** (`iris-...`) — мод для поддержки шейдеров. Работает в паре с Sodium и позволяет включать реалистичную графику.
4. **Mod Menu** (`modmenu-...`) — удобное меню для просмотра списка установленных модов и настройки их параметров прямо из игры.
5. **LambDynamicLights** (`lambdynamiclights-...`) — динамическое освещение. Факелы, светокамень и другие светящиеся предметы теперь освещают мир вокруг вас, когда вы держите их в руках.
6. **Xaero's Minimap** (`xaerominimap-...`) — удобная мини-карта в углу экрана с точками телепортации и отображением мобов/игроков.
7. **Xaero's World Map** (`xaeroworldmap-...`) — полноэкранная карта мира (дополнение к мини-карте), позволяющая исследовать уже открытые территории.

В папке `shaderpacks/`:
* **SFLP Shaders** (`sflp-shaders-standard-r1.zip`) — красивый и оптимизированный пакет шейдеров для реалистичных теней, воды и освещения.

## 🛠️ Как установить сборку новичку?

1. **Скачайте и установите Minecraft Launcher** (если еще не установлен).
2. **Установите Fabric Loader** для версии игры **1.26.3** с официального сайта [fabricmc.net](https://fabricmc.net/).
3. Запустите игру хотя бы один раз с профилем Fabric, чтобы создалась папка игры (`.minecraft`).
4. Откройте папку с игрой (в Windows нажмите `Win + R`, введите `%appdata%\\.minecraft` и нажмите Enter).
5. Скопируйте папки **`mods`** и **`shaderpacks`** из этого репозитория прямо в вашу папку `.minecraft` (если такие папки там уже есть, просто объедините их содержимое).
6. Запустите Minecraft с профилем **Fabric**, настройте шейдеры через меню графики Iris и наслаждайтесь игрой!
